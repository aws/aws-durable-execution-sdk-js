# Instructions for AI agents

`README.md` is the only documentation of this package. It holds the API, the best
practices, the rules and the design.

1. Before you change any file in this package, read `README.md`, including the
   "Contributing" section.
2. Always follow the rules in the "Contributing" section. When they and the full SDK
   disagree, the rules win inside this package.
3. Keep `README.md` correct. A change that alters behavior, a rule or the design updates
   the matching section in the same commit.
4. Do not add documentation to this file. Put it in `README.md`.
